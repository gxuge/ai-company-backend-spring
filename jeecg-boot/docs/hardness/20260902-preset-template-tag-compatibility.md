# 旧预设模板与固定标签词典兼容

## 分级
- 等级：H2
- 日期：2026-09-02

## 约束
- 不覆盖或重写 `role_core_fill_preset:v2`、`story_core_fill_preset:v2`。
- 不新增预设与标签关系表。
- 不改变角色、故事生成接口的请求和响应结构。
- 生成前识别结果只用于 Prompt 提示，不直接写入正式内容标签。

## 实现决策
- 从 `ts_tag` 查询对应内容类型下的启用标签。
- 合并预设名称、描述和用户输入，按标签名称做明确包含匹配。
- 按标签类型聚合后映射到旧模板变量，未识别字段统一传入 `null`。
- 正式标签继续沿用作品审核快照的异步 AI 打标流程。

## 风险与回滚
- 每次预设生成会增加一次标签词典查询，当前固定词典规模较小。
- 明确包含匹配优先保证可解释性，不自动扩展同义词。
- 回滚时移除生成服务中的适配器调用及适配器类，不涉及数据库回滚。
