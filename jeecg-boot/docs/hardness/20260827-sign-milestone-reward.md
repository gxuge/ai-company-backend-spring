# 20260827 连续签到里程碑奖励 Hardness

## 元信息
- 任务 ID：20260827-sign-milestone-reward
- 任务名称：连续签到第 4、7 天循环额外奖励
- 分级：H2
- 负责人：AI
- 时间窗口：2026-08-27
- 关联：`PLANS.md`、`docs/decisions/20260827-sign-milestone-reward.md`

## 目标与非目标
- 目标：支持后台配置签到周期第 1-7 天的独立奖励规则。
- 目标：连续签到第 4、7 天按 7 天周期重复触发，奖励幂等发放并独立记录。
- 目标：Vue3 活动后台可查询和编辑签到里程碑规则。
- 非目标：不改变断签重置逻辑，不改变每日签到基础奖励，不新增触发层行为类型。

## 输入约束
- 已知上下文：签到入口为 `TsActivityServiceImpl.sign`，奖励统一经过奖励事件中心和积分服务。
- 强约束：里程碑奖励不叠加会员奖励；同一用户、任务、周期轮次和周期天只能发放一次。
- 禁止事项：不得修改既有每日签到幂等键语义，不得提交敏感配置，不得改变统一响应结构。

## 任务分解
### T1 数据模型
- 输入：现有签到记录、活动任务和奖励记录表。
- 执行动作：新增里程碑规则表及签到记录周期、奖励流水字段。
- 输出：迁移 SQL、实体和 Mapper。
- 验收标准：数据库迁移可表达唯一规则及独立奖励流水。
- 证据类型：SQL 文件和编译结果。

### T2 发奖链路
- 输入：连续签到天数、签到任务、统一奖励事件中心。
- 执行动作：计算周期天与轮次，匹配规则并发布幂等奖励事件。
- 输出：第 4、7、11、14 天分别命中 4、7、4、7。
- 验收标准：里程碑奖励不叠加会员奖励且不误更新任务进度。
- 证据类型：单元测试。

### T3 后台配置
- 输入：活动后台 Controller、Service 和 Vue3 活动页面。
- 执行动作：新增规则查询/保存接口和签到里程碑标签页。
- 输出：管理员可筛选签到任务并维护周期天奖励。
- 验收标准：接口参数校验完整，前端表单限制周期天为 1-7。
- 证据类型：编译和前端类型检查。
