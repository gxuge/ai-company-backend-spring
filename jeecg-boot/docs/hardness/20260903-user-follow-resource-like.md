## 目标与非目标
- 目标：实现 5 个用户关注接口和 4 个资源点赞接口。
- 目标：写操作幂等，所有查询按当前登录用户隔离。
- 目标：分页大小限制为 1 至 100。
- 非目标：不修改前端、现有收藏语义和推荐算法。

## 输入约束
- 当前用户主键使用 `sys_user.id`。
- 点赞资源仅支持 `role`、`story`，且必须存在在线公开记录。
- Controller 只负责参数、登录态和统一响应，业务规则位于 Service。
- 新增 SQL 使用 UTF-8 without BOM，并提供影响范围和回滚语句。
