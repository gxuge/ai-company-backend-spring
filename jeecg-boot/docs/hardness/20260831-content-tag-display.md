# 角色与故事内容标签展示

## 任务分级
- 分级：H2
- 日期：2026-08-31

## 变更范围
- 内容标签服务新增按内容 ID、内容版本批量读取展示标签的能力。
- 角色与故事本人列表、详情、保存响应补充 `tags`。
- 公开角色与故事列表、详情补充 `contentVersion` 和 `tags`。
- Native 角色详情、故事浏览卡片和故事详情展示标签名称。

## 关键约束
- 仅返回与内容当前版本完全一致的标签，旧版本标签不可展示。
- 对外不暴露标签分数、生成来源、模型版本和内容哈希。
- 未打标内容返回空列表，不阻断原查询和页面展示。
- 列表使用批量查询，不按单条内容循环访问数据库。

## 验证与回退
- 使用单元测试验证版本过滤和展示字段映射。
- 使用 Maven 目标模块测试编译验证后端。
- 使用前端 TypeScript 或 Babel 定向检查验证页面。
- 回退只需撤销接口字段与页面展示，不涉及数据库结构。
