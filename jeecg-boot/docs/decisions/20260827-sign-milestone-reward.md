# ADR：连续签到里程碑按 7 天循环发奖

## 背景
现有签到只记录连续天数并发放每日固定奖励，无法在连续第 4 天和第 7 天
追加运营奖励。

## 决策
- 新增签到里程碑规则表，每条规则绑定签到任务和 1-7 的周期日。
- 连续签到总天数继续累加，周期日按 `((continuousDays - 1) % 7) + 1` 计算。
- 第 8 天进入下一轮第 1 天，第 11 天和第 14 天再次命中第 4 天和第 7 天规则。
- 每日签到与里程碑使用独立奖励事件和积分流水。
- 里程碑幂等键包含用户、签到任务、周期起始日期、周期轮次和周期日，
  避免断签后连续天数重置造成旧周期撞键。
- 里程碑奖励不重复应用会员签到加成，最终到账金额以规则配置为准。

## 影响
- 签到响应增加周期日、里程碑日、里程碑奖励和里程碑流水号。
- 活动后台新增签到里程碑规则查询和保存接口。
- Vue3 活动后台新增“签到里程碑”配置页签。

## 回退
- 将里程碑规则状态全部改为停用，签到立即恢复为仅发每日奖励。
- 如需删除表和字段，应先确认没有依赖里程碑流水的对账任务。
