# 活动条件拆分与主业务触发策略

## 状态
已接受，2026-08-27。

## 背景
活动中心原有 `IMAGE_GENERATE` 无法分别配置角色图片和故事背景奖励，也缺少
故事互动条件。活动进度如果直接参与主业务事务，还可能因活动表或奖励异常
导致聊天、创建或生成操作回滚。

## 决策
- 保留 `IMAGE_GENERATE` 兼容历史数据，新增 `ROLE_IMAGE_GENERATE`、
  `STORY_BACKGROUND_GENERATE` 和 `STORY_INTERACTION_COUNT`。
- AI 角色回复成功后推进 `CHAT_COUNT`；会话关联故事时同时推进
  `STORY_INTERACTION_COUNT`。
- 角色、故事和两类图片均在业务成功出口上报，并使用消息 ID、资源 ID或
  本次生成标识作为业务幂等 ID。
- 事务内调用在提交后执行；无事务调用立即执行。活动异常仅记录告警，不影响
  主业务结果。
- 默认任务使用 `AUTO` 发奖；周聊 100 次默认奖励 20 星钻。默认数据通过
  项目外独立补丁提供，不写入完整数据库基线或版本迁移。

## 影响
- 后台可独立配置两类图片和故事互动任务。
- 同一聊天事件可同时推进每日聊天和每周聊天任务。
- 活动进度是尽力上报，提交后进程立即退出时存在极小概率漏记。

## 回退
停用新增默认任务并移除业务入口上报调用即可；新增枚举和历史进度事件保留，
不会影响旧 `IMAGE_GENERATE` 配置。
