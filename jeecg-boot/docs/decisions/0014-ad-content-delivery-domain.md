# ADR：海报与广告独立运营投放域

## 背景
前端需要展示首页海报、轮播图、弹窗和广告等运营内容，并由后台配置上下线时间和目标人群。该能力与作品审核、评论审核的状态机和数据生命周期不同。

## 决策
- 新建独立广告投放域，不复用作品或评论审核表。
- 广告位、广告内容、投放规则和行为事件分别建表。
- 一个广告内容对应一条投放规则；规则缺失时按全平台、全用户、全会员等级处理。
- 客户端只传广告位编码和平台，登录状态、用户 ID、会员等级由后端计算。
- 公开投放采用批量候选查询，服务层完成 JSON 规则过滤和广告位数量截断。
- 曝光和点击事件使用客户端生成的 `eventId` 做幂等，不采集 IP。

## 影响
- 新增 `/sys/ts-ad-admin/**` 管理接口和 `/sys/ts-ads/**` 公开接口。
- 新增四张 `ts_ad_*` 表，不修改会员、作品审核和评论审核数据。
- 本期不创建后台菜单，待 Vue 管理页面完成后再绑定路由。
