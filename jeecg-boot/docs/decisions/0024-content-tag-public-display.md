# ADR 0024：内容标签按当前版本对外展示

## 状态
已接受，2026-08-31。

## 背景
角色与故事标签已经按内容版本写入 `ts_content_tag`，但现有本人接口和公开接口未返回标签，前端无法向用户展示内容特征。

## 决策
- 查询接口根据 `contentType + contentId + contentVersion` 批量读取标签。
- 返回独立展示结构：`tagId/typeCode/typeName/name`。
- 分数、来源、模型版本和内容哈希继续作为内部生产与分析字段，不进入用户接口。
- 未生成标签时返回空列表，保持原接口可用性。

## 影响
- 公开列表和本人列表会增加固定数量的批量查询。
- 内容版本变化后，只有新版本标签可见，避免展示过期定义。
- 前端可直接复用同一标签结构展示角色和故事。
