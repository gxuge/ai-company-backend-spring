# ADR-0023 行为事件保存服务端标签快照

## 状态
已采纳

## 背景
现有行为明细只记录资源 ID。内容标签会随内容版本更新，如果分析时再关联当前标签，
历史行为会被错误归因到新标签。

## 决策
- 行为发生时由服务端读取角色/故事当前版本及 `ts_content_tag`。
- Kafka v3 消息和 ClickHouse 明细保存 `content_version`、`tag_ids`、`tag_scores`。
- 客户端继续只提交业务行为，不允许提交标签。
- 前端批量事件按资源去重后批量补全；后端可信业务事件使用同一补全组件。
- 第一阶段只新增 `unfavorite`，不新增不喜欢和故事阅读进度事件。

## 影响
- 历史行为可按发生时标签稳定分析。
- 行为采集增加少量 MySQL 批量读取。
- 已有 ClickHouse 数据卷需要手动执行升级 SQL。

## 回退
回退事件 v3 Java 字段与写入映射。ClickHouse 新列保留默认值即可，不要求破坏性删列。
